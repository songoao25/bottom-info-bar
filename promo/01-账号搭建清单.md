# 抖音账号搭建清单（个人 IP 起步）

目标：陌生人刷到你主页时，3 秒内知道你是谁、能给他什么。

## 1. 账号基础
- **抖音号（ID）**：用英文名或拼音，别用随机串。例：`songoao25`（和 GitHub 统一，方便导流）
- **昵称**：人设 + 领域。例：「宋松 · AI工具实测」或「码农宋松」
- **头像**：真人照片优先（半身、干净背景、正脸清晰）。真人头像对 IP 信任度帮助最大。
- **简介（签名）**：一句话说清你是谁 + 你能提供什么 + 更新频率。
  - 模板：`{身份} | 专注{领域} | 每周{几}更新 | 帮你{解决什么}`
  - 例：`独立开发者 | 专注 AI 编码工具实测 | 每周 2-3 更 | 帮你把 AI 用得省、用得明白`
- **背景图**：放一张你最满意的成品截图 + 一句口号。

## 2. 风格定调
- 统一封面风格（字体、配色、版式），让用户刷到就认得出是你。
- 统一口头禅 / 开场白（钩子），强化记忆点。

## 3. 避坑
- 别一上来发硬广、别放外链（新号易被限流）。
- 简介里先不写"私信 / 加群"，号做起来再说。
- 前 5 条先养号（正常刷、互动），别上来就狂发。
