# Bottom Info Bar v1.2.0

新增「信息概览」页面——完整的使用追踪（费用 / 模型 / token / 明细），从**设置页**与**对话页顶部标签栏**两个入口进入同一个页面。

## ✨ 新增

- **「信息概览」页面（双入口）**：设置页左侧导航 + 对话页顶部标签栏均可进入，同一页面、同一份数据
- **花费总览卡**：今日 / 本月 / 近30天 / 累计 四个金额（口径与信息栏一致）
- **花费趋势图**：近 7 / 30 天每日花费柱状图（可切换，悬停查看金额）
- **各模型用量统计**：调用次数 / token / 费用，按费用降序 + 占比条
- **使用记录明细**：每一笔调用记录（时间 / 模型 / 服务商 / 输入·缓存·输出 token / 费用），最新在前，「加载更多」翻页
- **自动刷新**：页面每 30 秒自动更新；失败显示错误与「重试」

## 🔒 安全

- 页面数据全部来自本地记录文件（`usage-records.json`），不联网、不上传
- 接口仅返回展示所需字段，会话 ID 等内部信息零对外暴露

## 安装 / 升级

```bash
git clone https://github.com/songoao25/dsh-bottom-info-bar.git
cd dsh-bottom-info-bar
./install.sh                # 安装到 web profile；--profile <name> 覆盖
```

重启 DeepSeek Harness 后生效：打开 **设置 → 信息概览** 或 **对话页顶部标签栏 → 信息概览** 即可使用。

## 回滚

```bash
git checkout v1.1.0 -- plugin && cd plugin && npm run build && cd .. && ./install.sh
```

数据记录文件不受影响，无需迁移。
