# Safari Web App 视觉验收清单

每次改变信息栏布局、颜色或浮窗后，由用户手动重启 DSH，并在 Safari Web App 中完成以下检查：

- 浅色与深色外观：12px 的红色警示、绿色空闲价均清晰可读；红色不用于正常额度。系统启用“增强对比度”后，浅色外观应使用更深的红绿，深色外观应使用更亮的警示红。
- 低余额 / 低额度：显示无括号、紧贴数值的红色 `低` 字；无胶囊、底色或边框，不得与视觉能力胶囊争夺注意力。
- 服务商 / 模型：始终显示为“服务商 · 模型”；若模型全名以服务商开头，只移除模型部分的重复前缀（例如 `DeepSeek · V4 Flash`）。
- 字重：服务商、状态词、错误和更新提醒为 600；余额、额度、倒计时、花费和原生统计的数据令牌为 700；模型名和说明保持常规字重。
- 数值格式：标签在前，数值、单位、百分号和货币符号作为一个整体加粗。检查 `LLM 1.2s`、`输入 12K tok`、`余额 ¥3.00`、`距重置 3h 12m` 的数据令牌与标签层级一致。
- 中文混排：检查 `6 轮`、`12 步`、`5 小时`；数字与中文量词之间有空格，数值与西文/符号单位仍按 `1.2s`、`48%` 连写。
- 间距：外部信息组的 `|` 两侧各 6px；所有“标签—数据”边界固定为 4px（不使用普通字符空格）；服务商/模型之间的圆点两侧各 4px；数值后的 `低` 与数值相隔 3px。
- 视觉模型：服务商、圆点与 `#0057FF` 电光蓝胶囊共用垂直中心线；胶囊高度不超过邻近文字的字形边界。
- 长模型名：服务商与模型详情可作为两个完整单元换行；视觉胶囊在极窄宽度下保留“视觉”，模型名以省略号截断，完整名称仍可通过悬浮提示查看。
- 对齐：整条信息栏作为一个居中内容组，左右边界不超过上方对话框的内容边界。
- 错误：`刷新失败` 与其他错误排在居中信息组的末尾；同时有多项刷新失败时只显示一次。
- 交互：鼠标悬停可看到短说明；单击可切换完整/简洁信息密度。
- 辅助功能：焦点进入信息栏时，读屏先读出当前信息，再读出“按 Enter 或空格切换”的操作提示。
