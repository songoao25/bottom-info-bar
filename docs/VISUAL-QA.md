# Safari Web App 视觉验收清单

每次改变信息栏布局、颜色或浮窗后，在重启 `dsh web` 的 Safari Web App 中完成以下检查：

- 浅色与深色外观：12px 的红色警示、绿色空闲价均清晰可读；红色不用于正常额度。
- 视觉模型：服务商、圆点与 `#4F46E5` 胶囊共用垂直中心线；胶囊高度不超过邻近文字的字形边界。
- 长模型名：模型胶囊不遮挡、不错位；窄宽度下信息可换行。
- 对齐：整条信息栏作为一个居中内容组，左右边界不超过上方对话框的内容边界。
- 错误：`刷新失败` 与其他错误排在居中信息组的末尾；同时有多项刷新失败时只显示一次。
- 交互：鼠标悬停可看到短说明；单击可切换完整/简洁信息密度。
