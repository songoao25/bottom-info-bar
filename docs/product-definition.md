# 产品定义：信息概览页面（v1.2.0 新功能）

## 一句话定位
给「底部信息栏」插件新增一个 **「信息概览」页面**：让用户（个人开发者）在一页之内看清自己使用 AI Agent 花了多少钱、用了哪些模型、消耗了多少 token、具体每一笔使用记录，并且**可以从两个地方进入**（设置页 + 对话页顶部标签栏）。

## 背景
- 现有插件只在对话输入框下方显示一行精简信息（余额、本对话花费、今日/近一月/全部花费等）。
- 用户希望有一个"正经的页面"来**追踪 Agent 使用情况**——就像其他 AI 产品（ChatGPT、Claude、Codex 等）里的用量/账单页面一样。
- 已有基础设施：插件一直在本地持久化每笔 LLM 调用的 token 记录（`usage-records.json`），并内置各模型定价表——数据都在，缺的是一个展示页面。

## 目标用户
- 非技术的个人开发者（用户本人）。
- 关心"钱花哪了、模型用得多不多"的 DSH 使用者。

## 核心场景
1. 用户点开**设置 → 信息概览**：查看完整的使用追踪（花费、记录、模型、token）。
2. 用户在**对话页顶部标签栏**点「信息概览」标签：不离开对话也能随时查看用量。
3. 页面内：扫一眼今日/本月/近30天/累计花费 → 看最近使用记录明细 → 看哪个模型花钱多 → 看近 7/30 天花费趋势。

## MVP 范围（第一版做这些）
1. **花费总览卡**：今日 / 本月 / 近30天 / 累计 花费（与信息栏口径一致：按北京时区、按活动币种）。
2. **使用记录明细列表**：每条显示 时间、模型、服务商、输入/缓存/输出 token、该笔费用（最新在前，支持翻页/加载更多）。
3. **各模型用量统计**：按模型汇总 token 与费用，排序展示（哪个模型最费钱、最费 token）。
4. **花费趋势图**：近 7 天 / 30 天每日花费（简单柱状图，无需引入图表库）。
5. **双入口**：设置页 `settings.section` 注册「信息概览」页面；对话页顶部标签栏 `conversation.view` 注册「信息概览」标签。两个入口进入同一个页面组件。
6. 页面自动定时刷新（与信息栏同一数据源，无需手动刷新）。

## 明确不做（Out of Scope，v1.2.0）
- 不做导出 CSV/账单下载。
- 不做多币种同时展示（沿用现有"活动币种"口径）。
- 不做订阅额度管理/绑定（已有独立插件负责）。
- 不做云端同步、多设备共享。
- 不做费用预算设置/超支提醒（现有信息栏已有余额预警，页面内暂不加配置项）。
- 不删除/编辑历史记录（记录只读）。

## 成功指标
- 页面在两个入口均可正常打开并展示真实数据（今日/本月/累计花费与信息栏显示一致）。
- 使用记录明细与 `usage-records.json` 内容一致。
- 打开页面到数据可见 ≤ 1 秒（本地 RPC，无网络依赖）。
- 数据只读、零写盘改动、零新增依赖。

## 关键约束
- 沿用现有架构：host 端加 RPC、client 端加页面组件，全部在现有 bundle 内完成，**不引入新依赖、不引入构建工具变更**。
- 页面视觉与 DSH 主题一致（使用主题 token 变量）。
- 历史数据兼容：旧版 `usage-records.json` 无需迁移。
